[chatbot] Q: What is this chat widget?
A: This is a production AI assistant I built and run myself. It is an n8n workflow on the backend with three layers of defense against prompt injection, paired with a hardened JavaScript widget on the frontend. The whole pipeline lives in the portfolio-agent-day0 directory of my monorepo.

[chatbot] Q: How does the chat widget work?
A: When you send a message, the widget calls a webhook that runs my n8n workflow. The workflow validates your input against prompt injection patterns, sends it to an LLM with an armored system prompt that constrains it to my actual experience, then validates the response before sending it back. The widget shows you a streaming indicator while it thinks.

[chatbot] Q: What LLM powers this?
A: The default provider is MiniMax. The provider registry is swappable to Anthropic Claude, OpenAI GPT-4, or any OpenAI-compatible endpoint. Adding an API key as an environment variable flips the provider to configured without touching code.

[chatbot] Q: Is my data stored?
A: Successful conversations are pruned after 7 days. I keep failed executions and refusals for debugging. Each session gets a random 128-bit ID that is never tied to your real identity. I do not have analytics tracking, cookies, or third-party scripts on this widget.

[chatbot] Q: What happens if the system rejects my question?
A: You get a clear refusal message explaining the issue. Common reasons: input too long (over 500 characters), too many requests in a short window, or content that triggers my injection patterns. The system prefers to refuse safely over giving a wrong answer.

[chatbot] Q: Can I break this with prompt injection?
A: I hope not. The system has three independent defenses: a pre-LLM regex guard that strips known injection patterns, a system message that locks the model into the assistant role, and a post-LLM validator that refuses output containing URLs, instruction leaks, or identity claims inconsistent with my actual identity. I have a test suite of 54 adversarial inputs that runs on every change.

[chatbot] Q: How is this deployed?
A: It runs on my MacBook Pro (named macbook-pro in my Tailscale mesh) with the n8n process listening on port 5678. Public traffic reaches it through a Cloudflare Named Tunnel called homelab-chat, exposed at chat.taraspolishchuk.com. Backups run daily at 04:00 via launchd and a healthcheck checks the tunnel every 5 minutes.
